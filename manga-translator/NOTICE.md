# Third-party components

Этот репозиторий содержит код проекта Manga Translator и использует сторонние библиотеки и модели. Их лицензии и условия использования не заменяются MIT-лицензией этого репозитория.

- PaddleOCR / PaddlePaddle — см. официальную документацию проекта.
- Ultralytics — см. условия лицензирования Ultralytics.
- Hugging Face Transformers / Hub — см. лицензии соответствующих пакетов и моделей.
- NLLB-200 distilled 600M (`facebook/nllb-200-distilled-600M`) — см. карточку модели.
- Speech-bubble model (`huyvux3005/manga109-segmentation-bubble`) — см. карточку модели.
- Qwen2.5-3B-Instruct-GGUF — используется только опционально; см. карточку модели.
- llama-cpp-python — см. лицензию проекта.

Перед распространением производных моделей/весов пользователь должен самостоятельно проверить актуальные условия соответствующих правообладателей.
