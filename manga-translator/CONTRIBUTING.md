# Contributing

Спасибо за интерес к проекту. Pull request и issue приветствуются.

## Перед изменением кода

1. Создайте отдельную ветку.
2. Не добавляйте PDF, изображения страниц, веса моделей, кэши или логи.
3. Проверьте синтаксис:

```powershell
python -m py_compile .\manga_translator_v10_4.py
```

4. Если меняется установка — обновите README и соответствующие PowerShell-скрипты.
5. Если меняется поведение переводчика — обновите CHANGELOG.md.

## Pull request

Опишите:
- что изменилось;
- зачем это нужно;
- как проверяли;
- есть ли влияние на скорость, память или качество OCR/перевода.
